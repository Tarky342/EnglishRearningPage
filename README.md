# DCR English Lab（非公式）

株式会社第一コンピュータリソースの新卒採用・一般教養英語試験に向けた、**独自作成の問題で練習するWebアプリ**です。公式過去問ではなく、会社の試験内容・難易度・配点・合格基準を再現または保証するものではありません。

公式採用情報（試験科目の根拠）：
- https://www.dcr.co.jp/recruit/flow/
- https://www.dcr.co.jp/recruit/topics/20260210/

## すぐに使う

1. `index.html`をChrome / Edge / Safariなどのブラウザで開いてください。
2. 「5分スプリント」で初回の弱点を測定します。
3. 「インプット」で弱点のルールを1分で読み、「分野別演習」で12問解きます。
4. 「復習」画面で間隔反復。最後に「実戦模試」で時間内に解く練習をします。

全問題、画面デザイン、JavaScriptはHTMLファイル内に格納されており、**動作に外部API・通信・アカウント登録は不要**です。ファイルをWebサーバーに置いた場合も動きます。

## 問題構成（全365問）

- 基礎文法：219問（主語と動詞、時制、現在完了、助動詞、受動態、不定詞・動名詞、比較、関係詞、前置詞、接続詞、冠詞・名詞、品詞、仮定法）
- 基本・仕事・IT語彙：101問
- 短文・実務読解：45問（15パッセージ×3問）

※英語4択の独自教材です。実際の企業試験形式は公開されていません。

## システム仕様

- **学習**：16分野の「一文ルール→例文→ひっかけ→即演習」
- **ドリル**：5分/10問、12分/20問、弱点12問、分野別8/12/20問
- **弱点抽出**：未学習・正答率・回答速度・復習予定の重み付けにより優先出題
- **ミス補強**：ミス後、同分野の別問題をドリル内へ最大8問追加（設定からOFF可）
- **復習間隔**：不正解は10分後、正解は1日後→3日後→以降は段階的に延長する簡易アルゴリズム
- **模試**：20/30/40問と10/15/20/30分を選択、解答時の正誤非表示、終了後の解説
- **分析**：累計正答率、カバー率、分野別成績、直近7日間の回答量、演習履歴
- **操作**：数字キー1〜4で回答、Enterで次へ。スマートフォンでも操作可。
- **保存**：`localStorage`。学習データはサーバーへ送信されません。JSON書き出し・読み込みが可能です。

## 注意点

- 保存はブラウザ・URL単位です。シークレットモード、ブラウザデータ削除、ファイル移動等で履歴が消えたり別の履歴扱いになったりする可能性があります。「設定」のJSONバックアップを推奨します。
- 模試の85%はこのアプリで定めた**学習管理目標**であり、企業の合格基準ではありません。
- 現状は**英語科目のみ**を収録しています。CAB/SPI/情報分野は含んでいません。
- 「時間切れ」「途中終了」時の未回答は模試得点の分母に含めますが、個別の誤答回数には記録しません。

## 配布物

- `index.html` — ブラウザでそのまま使える完全版
- `questions.json` — 編集可能な問題データ
- `app_template.html` — 問題データを埋め込む前のHTMLテンプレート
- `build_bank.py` — 問題データを生成・検証するPythonスクリプト

問題を編集する際は `build_bank.py` のデータを更新して実行し、`questions.json` を再生成してください。HTMLへ再埋め込みするには、テンプレート内の `__DATA__` をJSON文字列で置き換えます。


## UI/UX最適化版の変更点（2026-11-19）

- ホームの主要操作を明確化し、復習期限が来ている場合は復習を先に提示。
- 今日の学習進捗をホームの目立つ位置に配置。
- スマートフォン下部のナビを「ホーム／学ぶ／演習／復習／その他」の5項目に整理。模試・分析・設定は「その他」からアクセス。
- 演習中はモバイルの下部ナビを隠して、問題と操作に集中できる画面に変更。
- 文字サイズ、行間、ボタンのタップ領域、コントラスト、フォーカス表示を改善。
- 進捗バーの読み上げ情報、操作確認ダイアログのキーボード操作、Enterキーの誤作動対策を追加。
- 既存の学習アルゴリズム、問題データ、保存キー `dcr-english-lab-v1` を維持。

## 教材・HTMLの更新手順

1. 問題を変更する場合は `build_bank.py` を編集し、`python build_bank.py` を実行（`questions.json` を生成）。`questions.json` を直接編集しても構いません。
2. `python rebuild_html.py` を実行すると、現在の `questions.json` が `app_template.html` に埋め込まれ、`index.html` が再生成されます。
3. HTML単体にはすべての問題とUI/JavaScriptが含まれ、通信や外部APIなしで利用できます。
